# Security

Please report a vulnerability privately to **security@cashsdk.com**, not in a public issue.
Include the package and version, what an attacker can do, and how to reproduce it. We reply
within two working days.

Things we treat as vulnerabilities in these packages:

- a server key, provider key or customer session reaching the browser, a log or a URL
- one customer reading or changing another customer's access or purchases
- access granted without a verified payment
- a webhook accepted without a valid signature

Only the newest published version of each package receives fixes.
